# Console-based-Connect-4-in-C#
A terminal-based Connect Four game built in C# featuring a solo mode against an AI and a local two-player mode.

## Features
- AI opponent using Minimax with Alpha-Beta Pruning 
- Two-player local mode
- Color-coded board (Green = Player, Red = AI/Player 2)
- Retro game-boy style console UI

## How to Run
1. Clone the repo
2. Open in Visual Studio or any C# IDE
3. Build and run `Program.cs`
4. Choose game mode and enter column number (1–7) to drop your piece
